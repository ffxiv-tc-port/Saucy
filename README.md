# Saucy

金碟遊樂園多款小遊戲的自動化與輔助插件。

原作者：[PunishXIV/Saucy](https://github.com/PunishXIV/Saucy)

## 功能

### 九宮幻卡（Triple Triad）
- 自動導航至九宮幻卡 NPC（含地圖連結、坐騎輔助）
- 自動開始對戰、自動出牌、自動要求重賽
- 自動開始卡片解鎖任務
- 追蹤卡片收藏、缺卡清單、NPC 解鎖狀態
- MGP／獎勵掉落追蹤

### 仙人微彩、仙人仙彩
- 仙人微彩（Mini Cactpot）：自動翻牌並求解最佳選擇
- 仙人仙彩（Jumbo Cactpot）：購票面板開啟時自動填入號碼並叫出購買確認框，扣款確認仍由玩家自行按下

### 快速賣重複卡
- 自動出售背包中重複的九宮幻卡卡片，可設定每種卡至少保留張數

### GATE 小遊戲自動化
- 暴風倖存者（Wind Blows）
- 空軍裝甲駕駛員（Air Force One）
- 登高跳跳樂大挑戰（Leap of Faith）
- 搶救小雛鳥大作戰（Cliffhanger）
- 必中一閃快刀斬魔（Slice is Right）
- 各遊戲皆提供自動前往 NPC 與參加 GATE 的選項

### 孤樹無援（Out on a Limb）
- 陸行鳥廣場伐木機小遊戲自動化

### 統計
- 累計、單場、每小時 MGP 收益等數據追蹤

## 指令

- `/saucy`：開啟主視窗
- `/saucy d`：除錯視窗
- `/saucy stop`：停止導航與自動化
